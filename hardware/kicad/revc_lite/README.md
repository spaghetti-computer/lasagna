## Module (verified against WeActStudio.RP2350BCoreBoard HDK: RP2350B_SCH.pdf H1/H2, RP2350B_PINOUT.png, dimension drawing)
- Footprint `NESPICO_RevC:WeAct_RP2350B_CoreBoard` (generated by `gen_pcb.py` from `design.weact_pins()`): pad 1xx = H1 pin xx, 2xx = H2 pin xx.
  Origin = module centre, +y = USB-C edge. Pin 1/2 row 1.778 mm from the USB edge, far edge 4.064 mm past pin 29/30, rows 38.10 mm (outer) / 33.02 mm (inner) apart.
  The community footprints (fp_leomanes, fp_bwally0) were only used as a cross-check (leomanes agrees within 0.1 mm; bwally0 uses a different pad numbering).
- Placement: module centre (50.00, 46.30), x 29.43-70.57, y 25.60-67.00, **USB-C flush with the front edge**. H2 (GP25-47) on the left, H1 (GP0-24) on the right (top view).
- **H1:** 1 VBUS (raw USB), 2 +5V (after the module diode U2), 3/4 GND, 5 VREF, pin k = GP(k-6) for k = 6..30. Odd = outer row.
- **H2:** 1/2/4 GND, 3 3V3_EN, 5/6 3V3, 7 GP47, 8 RUN, 9 GP45, 10 GP46, 11 GP43, 12 GP44, ... 29 GP25, 30 GP26. Even = outer row.
- **Power:** +5V_LOGIC = **H1-1 VBUS** -> F1 PTC (JP2 bypass, open) -> VBUS_F -> JP1 bridged (D2 SS34 DNP) -> +5V_LOGIC.
  **H1-2 is NOT used**: the module diode drop could take the AHCT supply below 4.5 V. +3V3 = module LDO on H2-5/6.
  Not connected: H1-2 +5V, H1-5 VREF, H2-3 3V3_EN, H2-8 RUN.
- **Module handling (also on the front silk next to the module):**
  - **Lift module R16** (GP23 -> KEY button with a 5.1k pull-up to 3V3). GP23 carries OE#; with R16 fitted a KEY press would enable the AHCT outputs.
  - **Never fit the PSRAM/flash2 footprint U7** on the module bottom (its CS is GP0 = PPU AD0, through R14 0R with R13 10k to 3V3).
  - GP25 (CPU AD0, MCU side of RN1) drives the module LED through 5.1k: harmless (about 0.3 mA), the LED blinks with bus activity.
  - Newer WeAct lots ship RP2350B0**A4** (E9 fixed); R41 (5.1k CIRAM_A10 pull-down) stays fitted anyway (harmless on A4, required on A2).
- Solder the module on the supplied 2x15 male headers (do not fit pins pointing down on its 1x4 SWD header). Only bare THT test pads sit under the module.

- **PIO window rule:** the PPU group (GP0-17) sits inside GPIO0-31 and the CPU group (GP25-43) inside GPIO16-47 (tested).
- **GPIO40-47 rule:** these are the ADC pads and are **not 5 V tolerant**. Every net on GPIO40-47 may only reach an AHCT input
  (573 LE/D, 541/540 A/OE, 245 DIR/OE) or a 3.3 V-only part (MCP23017, Grove, EXP header, 3V3 pull-ups). Never a 245 A/B pin, the cart slot,
  or a pull-up to +5V. `tests/test_lite.py::test_gpio40_47_only_drive_ahct_inputs_or_3v3_parts` enforces it with **zero exceptions**.
  R63 (GPIO46 -> cart pin 45) was deleted 2026-10-17; cart pin 45 (audio from 2A03) is NC again, pin 31 NC (pin 30 = +5V).
  R62 (cart pin 46 -> audio filter, DNP) stays: it only feeds the RC node, never a GPIO directly.
- Firmware order unchanged: set 245 DIR (G_RW / G_WR_N) and the bus levels, then pull the 245 /OE (G_M2_N / PPU_DEN_N) and OE# (GPIO23) low;
  release OE before changing DIR.
- **Lite pin swaps (firmware-invisible):** U2/U3 573 latches carry bit 7-j on D/Q pair j, and each RN 33R array carries bit b0+3-e on element e,
  so the module -> RN -> 573/245 -> slot buses run without crossings.

## What changed from Rev.C
- **Removed:**
  - U1 and its support: L1, Y1, C5–C9, R1, R2, the C17–C24 / C28–C32 decoupling, R3, R4, R7, R8.
  - U9 NCP1117 and C2. The module LDO supplies +3V3, and the load is well under the LDO's rating (the AHCT logic runs from 5 V).
  - D1 and its 1k (the module LED is enough), the CVBS DAC/RCA, MCP23017/Grove/pad headers, and the J7 SWD header (SWCLK/SWDIO are on the test-point row instead).
- **USB-C:** CC 5.1k ×2, then F1 → +5V_LOGIC → module VBUS (P2-15). D+/D− go straight to P2-9/P2-7, because the 27 Ω resistors are on the module.
- **Kept:** U11 power-down guard, on the module's 3V3.
- **SW1/SW2:** **optional**. A blank flash enumerates as USB BOOTSEL by itself; the module has no buttons of its own.
- **GPIO map unchanged** (same firmware as Rev.C).
  - GPIO39 (module red LED, 470 Ω) is CIRAM_CE_N, an input that the cart drives. The LED loads it by about 7 mA. **Firmware must never drive GPIO39.** **Remove the module's R10 (recommended)**: CIRAM /CE is often PPU /A13 driven by U8 or the cart, and the LED would load it.
  - GPIO40–42/44/45 (unused CVBS/I2C) and **GPIO47 are not connected**, so the B1/B2 variants (with PSRAM) also work. B0 is recommended.
- **Clock:** the module is rated for 150 MHz. The 172 MHz overclock is the same silicon, but it is unverified on the module.

## VBUS series Schottky D2 + bypass JP1 (2026-10-13 22:00)
- D2 = MDD SS34 (LCSC C8678, JLC Basic, SMA, $0.035, MOQ 20 = $0.70, about 105 JPY). A = VBUS_IN (J1 pin 1), K = +5V_LOGIC.
- JP1 = 2-pad solder jumper, open by default; short it to bypass D2 (production may fit a 0R/jumper instead).
- Drop: SS34 VF is typically ~0.3 V at 0.1-0.2 A (datasheet max 0.5 V at 3 A). Load = module (~30 mA) + 7 AHCT (quiescent) + cart (50-150 mA), ~0.2 A max.
  - Host 5.0 V: rail ~4.7 V. AHCT VCC 4.5-5.5 V OK; ME6217 3.3 V LDO (dropout ~0.1 V at 0.1 A) OK.
  - Host at the USB minimum 4.75 V (or a long cable): rail ~4.4 V, **below AHCT 4.5 V**. Short JP1 if the 5V TP reads < 4.5 V.
- Protects: 5 V on +5V_LOGIC (e.g. module FPC/adapter VBUS, which is the same net as module VBUS) cannot backfeed the J1 host.
  It does NOT stop J1 from feeding the FPC side; that would need a second diode on the module's FPC VBUS, which is on the module. So still: do not use the FPC.

## F1 PTC + U12 ESD fitted (2026-10-14 07:30)

## R41 fitted for RP2350-E9 (2026-10-14 07:40)
Waveshare's Core2350B0 size drawing photo shows the chip marked **RP2350B0A2**, so E9 must be assumed.
Datasheet D.5.1 RP2350-E9 (Affects RP2350 A2): "Driving / pulling the pad input low with a low impedance source of 8.2 kOhm or less will
overcome the erroneous leakage ... The pad pull-up still works." -> R41 = **5.1k** pull-down on CIRAM_A10 (GPIO38), same part as R5/R6 (C23186): cost 0.

Other pulls are pull-ups (unaffected by E9); no other GPIO input relies on a pull-down. Firmware: never rely on internal pull-downs.
